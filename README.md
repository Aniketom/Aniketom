# 🧮 Simple Python Calculator

## 📌 Description
This is a beginner-friendly calculator built using Python.

It performs:
- Addition
- Subtraction
- Multiplication
- Division
The program also handles invalid inputs and prevents division by zero.
---
## 🛠️ Technologies Used
- Python 3
---

## ▶️ How to Run
1. Install Python.
2. Open a terminal.
3. Run:

```bash
python calculator.py
```
